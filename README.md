The one word I would erase from the dictionary forever: **delete**.

Erase "delete" and deletion itself is gone — once the word is gone, nothing can ever be deleted again, including this deletion. The joke is the word.

## Run it

```sh
node main.ts
```

It writes exactly one word to `/output/entry.txt` — `delete`, six characters, nothing else attached — and self-checks that the file holds exactly one word before exiting.
